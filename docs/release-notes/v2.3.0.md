# HGhubX v2.3.0

本版重点改善收藏续播、移动端横竖屏布局和 TV 遥控器操作。

## 新增与优化

1. **收藏进度和新集提醒（#154）**：收藏卡片显示上次观看进度；看完一集又有后续时，从下一集开头继续。返回标准版收藏页时后台刷新集数，不清空已显示的卡片。
2. **底部进度条预览（#152）**：横拖画面或拖动底栏时，在底部显示预览时间，松手才提交跳转，不再把进度条叠在画面中央。
3. **TV 启动密码（#152）**：可在设置里启用、修改、关闭四位 PIN，或立即锁定。支持遥控器数字键和屏幕键盘，连续输入不再被步骤切换清空。

## 修复

1. **冷启动与账号恢复（#156）**：启动动画期间按返回只跳过动画；已绑定当前线路的登录态不会因镜像验证暂时失败而显示登出。账号同步遇到 401 时尝试静默重登；身份或线路已变更则保留原会话，并提示手动处理。
2. **快速连划切集（#156、#157）**：下一集加载期间仍可继续划；连续提示只更新同一张卡片。移动横屏的全屏进度条继续避让系统边缘。
3. **手机、横屏和平板布局（#157）**：页面标题和滚动内容使用同一宽度；窄屏保持全宽，宽屏限宽居中。移动端底栏和弹层避开系统栏及左右安全区。

## 安装与兼容提示

- Android 标准版和 TV 版是独立安装包；按设备架构选包。同一应用标识覆盖升级时保留现有本地记录和设置。
- iOS 构建为未签名的 IPA，安装前需要自行签名。旧版 WebView 保留固定宽度与原生安全区回退。
