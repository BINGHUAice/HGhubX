# HGhubX v2.2.2

相较 v2.2.0，本版改善收藏续播、滑动切集、移动端布局和 TV 启动解锁。

## 新增与优化

1. **收藏进度、续播与新集提醒（#154）**：收藏卡片显示观看进度；看完一集且有后续时，从下一集开头继续。返回标准版收藏页时在后台刷新集数，保留已显示的卡片和原有断点。
2. **底部进度预览与连续切集（#152、#156、#157）**：横拖画面或拖动进度条，都在底部预览位置，松手才跳转；下一集加载时仍可继续划，同类提示只更新一张卡片。移动端全屏底栏避开系统边缘。
3. **TV 启动密码（#152）**：在设置里可开启、修改、关闭四位 PIN，或立即锁定。遥控器数字键与屏幕键盘均可输入；快速连按不丢数字，解锁页不再显示重复说明。

## 修复

1. **冷启动和账号同步（#156）**：启动动画期间按返回只跳过动画；镜像临时不可用时，保留当前线路的登录显示。账号同步收到 401 时尝试同账号静默重登；账号或会话已变化时不覆盖原会话。
2. **移动端布局与登录键盘（#157、#163）**：窄屏全宽，平板和桌面内容限宽居中；横竖屏底栏及弹层避开系统边缘。Android 标准版键盘打开后，密码框和「登录」仍可滚到可见位置。

## 安装与兼容提示

- Android 标准版与 TV 版为独立 APK，按架构选择；同一应用标识覆盖安装保留本地记录和设置。Android `versionCode` 为 `2002002`，已安装更高版本号的测试包时，系统可能拒绝直接覆盖。
- iOS 产物为未签名 IPA，安装前需要自行签名。
